# 前端小程序（miniapp/）

uni-app（Vue 3 + Vite + Pinia + SCSS）微信小程序，包含用户端 28 个页面 + 管理后台 20 个页面。

## 结构

```
miniapp/
├── src/
│   ├── api/
│   │   ├── index.js           # 用户端 30+ API 方法
│   │   └── adminApi.js        # 管理后台 API 方法（ADMIN_SECRET 认证）
│   ├── common/
│   │   ├── request.js         # 统一请求层（token 刷新、401 跳登录、GET 重试）
│   │   ├── constants.js       # 业务常量与工具函数
│   │   ├── config.js          # 环境配置（API_BASE、UPLOAD_BASE）
│   │   ├── storage.js         # 本地存储封装
│   │   └── payment.js         # 支付参数处理
│   ├── components/
│   │   ├── CustomTabBar.vue   # 底部导航栏（5 tab）
```

## 关键设计

### 路由
- 5 个 tabBar 页面：首页、大厅、发布、CRM、我的
- 34 个页面路由（pages.json 配置）
- 管理后台独立路由，登录页使用 `navigationStyle: custom`

### 状态管理
- Pinia：`store/user.js` 管理登录态（token/refreshToken/userInfo）
- 页面本地状态：Vue 3 ref/reactive + computed

### 请求拦截
- `request.js`：自动携带 Bearer token
- 401 时尝试 refreshToken 刷新后重放，失败则清空登录态跳转登录页
- GET 网络异常 / 5xx 自动重试一次
- 统一错误处理：非 0 code 抛出错误

### 代理配置
- H5 开发环境：Vite proxy 将 `/api` 和 `/uploads` 代理到 `http://127.0.0.1:3001`
- 微信小程序：微信开发者工具中勾选「不校验合法域名」

## 启动命令

```bash
# H5 开发服务器（端口 5174）
cd miniapp && npm run dev

# 微信小程序
cd miniapp && npx uni

# 测试
cd miniapp && NODE_PATH=$(npm root -g) npx vitest run
```
