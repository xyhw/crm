# 服务层（services/）

服务层封装核心业务逻辑，供路由层调用。每个服务职责单一，独立可测试。

## 服务清单

### account-lock.service.js
**职责**：账号级登录失败锁定  
**功能**：基于 `login_failures` 表，在窗口期（默认 900 秒）内连续失败达到阈值（默认 5 次）则锁定账号。支持记录失败和手动清零。

### audit-log.service.js
**职责**：操作审计日志  
**功能**：提供 `recordLog` 写入 `operation_logs` 表，以及 `audit` 中间件工厂，在管理后台操作成功时自动记录操作者、动作、目标、IP。

### level.service.js
**职责**：会员等级系统核心引擎  
**功能**：
- 用户等级查询（`getUserLevel`）
- 等级配置获取（`getLevelConfig`）
- 购买折扣计算（`calculateDiscount`）
- 分佣率计算（`calculateCommissionRate`）
- 免审判断（`isFreeAudit`）
- 标记权重获取（`getMarkWeight`）
- 购买价格计算（`calculatePurchasePrice`）
- 卖家收入计算（`calculateSellerIncome`）
- 全量等级重算（`recalculateAllLevels`）

**等级计算维度**：购买率 / 无效率 / 有用率 / 活跃度

### mail.service.js
**职责**：邮件发送  
**功能**：开发环境打印到日志，生产环境通过 SMTP 真实发送。用于密码重置验证码。

### similarity.service.js
**职责**：商机相似度检测  
**功能**：基于 TF 向量余弦相似度 + 编辑距离的混合算法，检测新投稿与现有 active 商机的相似度，防止重复投稿。阈值默认 0.80。

### wechat.service.js
**职责**：微信小程序开放能力封装  
**功能**：
- `code2Session`：wx.login 换 openid
- `getPhoneByCode`：获取微信手机号
- access_token 内存缓存

### file-magic.js
**职责**：文件魔数校验  
**功能**：校验上传文件的真实内容头字节与扩展名是否匹配，防止伪造文件上传（如图片伪装可执行文件）。

### payment/ 支付适配器

| 文件 | 职责 |
|------|------|
| `base.js` | 支付适配器基类，定义统一接口（createPayment/verifyNotify/parseNotifyResult/buildNotifyResponse） |
| `mock.js` | Mock 支付适配器，开发环境使用，支持自动完成支付 |
| `wechat.js` | 微信支付适配器（JSAPI） |
| `alipay.js` | 支付宝适配器 |
| `stripe.js` | Stripe 适配器 |
| `waffo.js` | Waffo Pancake 适配器 |
| `index.js` | 支付服务门面，提供适配器获取、渠道列表、创建充值订单、结算充值订单、查询订单 |
| `config-loader.js` | 支付配置加载器，从 DB 热更新 `system_configs` 中的 pay_* 配置 |

## 调用关系

```
routes/ → services/ → db.js
         → payment/ → system_configs
```

路由层负责参数校验和权限控制，服务层负责业务逻辑，数据层负责 SQL 操作。
