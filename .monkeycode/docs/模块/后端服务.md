# 后端服务（server/）

Express + MySQL 后端服务，提供 RESTful API、认证授权、业务逻辑、数据持久化、定时任务。

## 结构

```
server/
├── index.js                  # 入口：初始化 DB、迁移、种子、启动 HTTP + 调度器
├── config.js                 # 环境变量加载与全局配置
├── db.js                     # MySQL 连接池封装（query / queryOne / insert / update / transaction）
├── constants.js              # 业务常量（分类、状态枚举、匿名化工具）
├── auth.js                   # JWT 签发/验证 + authRequired / optionalAuth / adminAuthRequired
├── middleware/
│   ├── rate-limit.js         # 内存限流（API 60s/300次，登录 60s/10次）
│   ├── require-role.js       # 角色权限中间件
│   └── cache-headers.js      # HTTP 缓存头设置
├── routes/
│   ├── auth.routes.js        # 认证（微信登录/注册/登录/密码重置）
│   ├── opportunity.routes.js # 商机（列表/详情/发布/编辑/标记无效）
│   ├── order.routes.js       # 订单（购买/我的订单）
│   ├── points.routes.js      # 积分（余额/流水/充值/支付回调）
```

## 关键设计

### 认证
- 用户端：JWT（access 7天 + refresh 30天），401 自动 refresh
- 管理端：独立 `ADMIN_SECRET`，双权限校验（authRequired + requireRole）
- Token 失效：密码重置/封禁后 `token_version` 递增，旧 Token 全部失效

### 权限
- 4 个预置角色：super_admin / operation / finance / support
- 管理后台路由通过 `requireRole(...)` 声明所需角色
- 角色-权限关联存储在 `role_permissions` 表

### 限流
- API 全局限流：60 秒 300 次（内存计数器）
- 登录/密码重置独立限流：60 秒 10 次
- 账号级锁定：同一账号 900 秒内连续失败 5 次锁定

### 数据初始化
- 启动时自动执行 `initDatabase` 创建全部表
- 按序执行 16 步幂等迁移
- 加载种子数据（分类、等级、配置、默认管理员）
- 加载支付渠道配置（从 DB 热更新）

### 定时任务
- 每 24 小时执行：
  1. `recalculateLevels`：重算所有用户会员等级
  2. `cleanExpiredPoints`：清理过期积分（默认 180 天）
  3. `cleanExpiredNotifications`：清理 90 天前已读通知

## 启动命令

```bash
# 开发/生产统一启动
cd server && npm run dev

# 带自定义限流（用于测试）
RATE_LIMIT_LOGIN_MAX=999999 node --env-file-if-exists=.env index.js
```
