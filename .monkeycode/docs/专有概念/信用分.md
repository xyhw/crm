# 信用分

信用分是用户在平台上的信誉量化指标，范围 0-100，通过用户的负面行为扣除，正面行为加分，低于阈值将触发限制或封禁。

## 什么是信用分？

信用分反映用户在平台上的可信赖程度。初始值为 60（可通过系统配置调整）。

**加分行为**：
- 进展同步被标记有用：+1

**扣分行为**：
- 发布的商机被标记无效：-5（由系统配置 `invalid_penalty_rate` 决定比例）
- 进展同步被判无效（多人举报）：-5
- 举报他人进展被判不成立：不扣分（只有自己的行为影响自己）

**阈值**：
- `credit_review_threshold`（默认 60）：低于此值进入人工审核状态
- `credit_ban_threshold`（默认 40）：低于此值自动封禁（status = banned）

**恢复机制**：
- 信用分每次变动记录到 `user_credits` 表
- 扣分使用 `GREATEST(0, credit_score - delta)` 确保不低于 0
- 加分使用 `LEAST(100, credit_score + delta)` 确保不超 100

## 代码位置

| 方面 | 位置 |
|------|------|
| 数据库表 | `users`（credit_score）、`user_credits`（变动记录） |
| 后端逻辑 | `server/routes/follow-up.routes.js`（进展举报判无效扣分）、`server/routes/opportunity.routes.js`（商机无效标记扣分） |
| 前端页面 | `miniapp/src/pages/community/credit.vue` |
| API 方法 | `miniapp/src/api/index.js` 中的 `credits` |
| 系统配置 | `system_configs.credit_review_threshold`、`credit_ban_threshold` |

## 信用分变动记录

每次变动在 `user_credits` 表记录快照：

| 字段 | 描述 |
|------|------|
| `credit_score` | 变动后的当前分数（快照） |
| `change_amount` | 变动值（正数加分，负数扣分） |
| `change_reason` | 变动原因 |
| `source_type` | 来源类型（invalid_mark / share_report / purchase / share_helpful / admin_adjust 等） |

## 生命周期

```
初始 60 分
    ↓ 正常使用
保持高分（优质行为加分）
    ↓ 负面行为
逐步扣分 → 60 分以下进入人工审核 → 40 分以下自动封禁
    ↓ 封禁后
无法登录/使用平台核心功能
```
