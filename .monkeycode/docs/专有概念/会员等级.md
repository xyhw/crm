# 会员等级

会员等级是用户的成长体系，根据用户在平台上的购买行为、内容质量、活跃度等指标自动计算，不同等级享受不同的购买折扣、分佣奖励和特权。

## 什么是会员等级？

会员等级用于激励优质用户行为。系统根据四个维度综合评分：

- **购买率**：购买商机数量占总浏览量的比例
- **无效率**：标记无效的商机占比（越低越好）
- **有用率**：进展被点赞数占总同步数的比例
- **活跃度**：综合活跃行为得分

四个等级由低到高：普通（normal）→ 银牌（silver）→ 金牌（gold）→ 认证达人（expert）。

**关键特征**：
- 自动计算：每 24 小时定时重算所有用户等级
- 折扣激励：等级越高，购买商机折扣越大（7 折 ~ 全价）
- 分佣奖励：等级越高，出售商机获得的分佣比例越高（0% ~ 30%）
- 免审特权：gold 和 expert 等级的进展同步可跳过人工审核
- 标记权重：高等级用户的「有用」标记权重更高

## 计算公式

### 综合得分

```
composite_score = purchase_rate * 0.3 + (100 - invalid_rate) * 0.25 + helpful_rate * 0.25 + activity_score * 0.2
```

### 购买价格

```
actualPrice = price * (1 - discountRate)
sellerIncome = actualPrice * (1 - platformCommissionRate) * (1 + commissionBonus)
```

### 等级判定

用户等级根据 `composite_score` 和各维度阈值判定，满足所有阈值条件则升级。

## 定时任务

`scheduler.js` 每 24 小时执行一次 `recalculateLevels`，遍历所有用户重新计算等级并更新 `user_level_stats` 表。
