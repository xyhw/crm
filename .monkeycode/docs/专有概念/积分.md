# 积分

积分是平台内的虚拟货币，用于购买商机、充值、参与社区激励。用户通过注册、邀请、出售商机、进展同步被点赞等行为获得积分，消费用于解锁商机详情。

## 什么是积分？

积分是平台内的流通凭证，贯穿核心交易链路：发布商机定价 → 购买者支付积分 → 卖家获得积分（扣除平台抽成）→ 积分可用于继续购买其他商机或充值。

**获取途径**：
- 注册赠送：`register_gift_points`（默认 10）
- 邀请奖励：`invite_reward_points`（默认 5，双方各得）
- 出售商机收入：`sellerIncome`（买家支付的实际积分，扣除平台抽成）
- 进展同步奖励：审核通过 +2，被点赞 +1
- 充值购买：通过 Mock / 微信 / 支付宝 / Stripe / Waffo 渠道充值

**消耗途径**：
- 购买商机：支付 `actualPrice` 积分
- 积分过期：奖励积分有效期 `points_expire_days`（默认 180 天）

**规则**：
- 积分账户：`points_accounts` 表，主键 user_id，实时余额
- 流水记录：`points_logs` 表，每笔变动记录 delta、balance_after、source_type
- 过期清理：scheduler 每 24 小时清理过期积分

## 积分来源类型（source_type）

| 类型 | 描述 | delta |
|------|------|-------|
| register_gift | 注册赠送 | + |
| invite_gift | 邀请奖励 | + |
| purchase_income | 出售商机收入 | + |
| commission | 分佣奖励 | + |
| reward | 社区奖励（进展同步/被点赞） | + |
| consume | 购买商机消费 | - |
| expire | 积分过期 | - |
| recharge | 充值 | + |
| admin_adjust | 管理员调整 | +/- |
| refund | 退款返还 | + |
| penalty | 惩罚扣除 | - |

## 充值流程

1. 用户选择金额和渠道，调用 `POST /api/points/recharge`
2. 后端创建 `payment_orders` 记录，返回支付参数
3. 用户完成支付（或 Mock 自动完成）
4. 渠道异步通知 `/api/points/recharge/notify/:channel`
5. 后端验证通知，更新订单状态，增加积分余额
6. 用户查询订单状态或自动跳转结果页
