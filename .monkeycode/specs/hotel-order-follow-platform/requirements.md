# 酒店供应链跟单互助平台 · 综合需求文档

> 版本：v1.0
> 日期：2026-08-04
> 适用对象：产品、开发、测试、项目管理、外包协作
> 项目形态：H5 用户端 + Web 管理后台 + 后端 API 服务
> 说明：本文档由《商机平台正式需求文档 v4.0》与现有《酒店供应链在线跟单系统》需求综合而成，业务领域聚焦酒店装修供应链，机制上吸收商机平台完整 V1 能力。

## 1. 项目概述

### 1.1 项目背景

酒店从筹建到开业需要大量物资采购与总包服务，涉及装修总包、弱电总包、软装总包、酒店家具、酒店运营物资等细分领域。各供应商在项目跟进中存在大量"人找单、单找人"的信息不对称，跟进资源分散、重复劳动、信息难以验证。

本平台基于**商机共享经济模型**构建酒店供应链供应商互助协作平台，核心理念为"人人分享，人人受益"。平台不生产跟单内容，而是通过**积分激励**促进供应商投稿跟单、购买跟单、共享有效跟进进度，形成跟单信息的自循环生态，同时扮演信任背书、价值分配与信息聚合的角色。

### 1.2 项目目标

- 搭建酒店供应链领域用户驱动的跟单共享与跟进管理平台
- 打通"投稿跟单 → 即时上架 → 积分购买 → 跟进共享 → 分佣激励 → 持续投稿"的完整飞轮
- 通过积分体系和会员等级体系实现平台可持续运营
- 为用户提供个人 CRM 工具，提升跟单管理效率和平台粘性

### 1.3 项目范围

本期建设范围为 V1 MVP 完整版，重点实现：

- H5 用户端登录与跟单浏览
- 跟单投稿即上架机制（相似度检测提示）
- 积分购买跟单与会员折扣体系
- 用户共治的跟单质量验证机制（无效判定与退款）
- 个人 CRM 跟单管理系统
- 跟进记录与匿名进度共享
- 积分激励与分佣结算
- 会员等级与信用分体系
- 邀请机制、排行榜、通知中心
- Web 管理后台（RBAC 权限、跟单管理、审核、订单、财务、统计）

## 3. 核心商业逻辑

### 3.1 跟单共享飞轮

```
供应商投稿跟单 → 即时上架（相似度检测提示）
        ↓
其他供应商用积分购买（充值或奖励积分）
        ↓
投稿人获得积分分佣（平台抽成后）
        ↓
购买者跟单自动入库个人 CRM → 跟进管理
        ↓
填写私有跟进记录 → 选择共享匿名进度
        ↓
共享摘要经审核后展示 → 被标记"有用"获得积分
        ↓
系统聚合所有跟进 → 更新跟单市场情报
        ↓
多人标记无效 → 自动退款 + 惩罚投稿人
        ↓
积累高质量记录 → 提升会员等级 → 更高分佣和折扣
        ↓
继续购买其他跟单 → 飞轮持续转动
```

### 3.2 平台角色定位

平台扮演三个角色：

1. **规则制定者**：设定积分规则、分佣比例、等级体系
2. **信任背书方**：审核共享内容、处理无效跟单、维护信用体系
3. **信息聚合器**：聚合跟进情报、提供发现机制、优化用户体验

平台不参与跟单内容生产，不判断跟单质量，只维护生态规则和价值分配机制。

## 5. 核心业务规则

### 5.1 跟单可见规则

跟单字段分三层：

- **公开字段**：标题、分类、标签、简要描述、发布时间、市场情报摘要（购买人数、跟进热度）
- **解锁字段**：完整描述、联系方式（联系人/电话）、附件、自定义字段、详细市场情报（匿名跟进摘要列表）
- **管理字段**：投稿人、内部备注、无效标记记录、分佣结算状态

游客和未购买会员仅可查看公开字段；已购买用户可查看解锁字段。

### 5.2 积分体系规则

积分类型：
- 统一积分，不区分充值积分和奖励积分
- 奖励积分有效期由超级管理员后台统一配置
- 充值积分永久有效
- 积分到期前 N 天系统发送提醒通知
- 过期积分自动清零，记入流水

积分来源：
- 注册赠送（后台可配金额）
- 邀请好友注册（邀请人和被邀请人均获得，注册即发）
- 跟单分佣（购买量 × 价格 × (1 - 平台抽成比例)）
- 跟进共享奖励（提交共享摘要）
- 共享摘要被标记有用（每次标记获得奖励）
- 后台人工调整
- 充值兑换（1:1 比例，mock 模式模拟）

积分用途：
- 购买跟单解锁权限
- 不支持提现、不支持兑换实物（取消商城兑换，后台保留开关，未来可开启实物/虚拟兑换）

积分规则：
- 所有积分变动必须有流水记录
- 充值积分不支持退款（用户协议明确）
- 奖励积分不支持提现
- 建议用户小额充值，单次充值上限后台可配

### 5.3 跟单投稿与上架规则

投稿流程：
- 会员填写跟单表单（标题、分类、标签、描述、联系方式、附件、预计有效期、定价）
- 系统实时检测标题相似度（≥80% 触发提示）
- 提示用户"已存在相似跟单，是否继续？"，不强制阻止
- 用户确认后即时上架，无需人工审核
- 第一个投稿者为该跟单所有人，享有分佣权益

从 CRM 投稿：
- 用户可将个人 CRM 中的跟单一键投稿到平台
- 投稿流程与普通投稿完全一致，同样走相似度检测

跟单定价：
- 所有人统一价格区间，由超级管理员后台设置（如 10~200 积分）
- 投稿人在区间内自主定价
- 会员等级不影响定价权限，仅影响购买折扣

### 5.4 跟单购买规则

购买流程：
- 用户点击解锁跟单
- 系统判断跟单发布时间，超过 1 年提示"该跟单发布已超过 1 年，可能存在时效性问题，是否继续购买？"
- 用户确认后扣除积分（原价 × 会员折扣）
- 平台抽取配置比例积分
- 剩余积分分佣给投稿人
- 跟单自动入库到用户个人 CRM
- 记录购买订单和积分流水

统一规则：
- 同一用户对同一跟单仅需购买一次
- 购买成功后永久拥有该跟单访问权
- 已购买跟单不重复扣费
- 购买行为必须记录到数据库

### 5.5 跟单无效判定规则

标记流程：
- 购买者可标记跟单为"无效/虚假/重复"
- 标记时必须选择原因（联系方式无效、信息虚假、重复跟单、其他）
- 当标记人数 ≥ 购买量 × 系统配置比例（后台可配，建议 20%）时触发无效判定

判定后处理：
- 系统自动退还所有购买者积分
- 投稿人扣除积分惩罚（扣除比例后台可配）
- 投稿人信用分扣除（-10 分）
- 跟单状态标记为"无效"并下架
- 保留历史记录供后台查看
- 投稿人累计 N 次无效触发封号（N 后台可配，建议 3 次）

### 5.6 会员等级规则

等级评定维度：

| 维度 | 说明 | 权重 |
|------|------|------|
| 投稿购买率 | 投稿跟单被购买的比例 | 40% |
| 投稿无效率 | 投稿跟单被判无效的比例（越低越好） | 30% |
| 跟进有用率 | 共享摘要被标记有用的比例 | 20% |
| 平台活跃度 | 注册时长、登录频率、操作频次 | 10% |

等级权益（后台可配，建议值）：

| 等级 | 晋升条件示例 | 购买折扣 | 分佣比例加成 | 其他权益 |
|------|--------------|----------|--------------|----------|
| 普通会员 | 注册即获得 | 无折扣 | 标准比例 | - |
| 银牌会员 | 投稿购买率≥30%，无效率≤10% | 9 折 | +10% | - |
| 金牌会员 | 投稿购买率≥50%，无效率≤5% | 8 折 | +20% | 共享摘要免审 |
| 认证达人 | 投稿购买率≥70%，无效率≤3% | 7 折 | +30% | 共享摘要免审 + 无效标记权重 3x |

等级变更：
- 系统每日凌晨自动计算用户等级
- 等级变更实时生效
- 等级变更时发送通知

### 5.7 信用分体系规则

每个用户初始信用分 100 分：

扣分项：
- 投稿跟单被判无效：-10 分
- 共享摘要被举报并确认：-5 分
- 账号被举报并确认：-3 分

加分项：
- 投稿跟单被购买：+2 分
- 共享摘要被标记有用：+1 分
- 持续活跃（每周登录≥3 天）：+1 分/周

信用分对应限制：
- 80 分以上：正常使用所有功能
- 60~80 分：投稿跟单需要审核才能上架
- 40~60 分：禁止投稿，只能购买和跟进
- 40 分以下：账号封禁

### 5.8 跟进与 CRM 规则

个人 CRM：
- 用户购买跟单后，跟单自动入库到个人 CRM
- 用户可手动录入平台外获取的跟单到 CRM
- CRM 支持跟单管理、跟进记录、提醒设置
- CRM 数据完全私有，平台不读取、不展示

跟进记录分层：

**私有层（只有自己可见）**：
- 联系人姓名、电话
- 具体谈判内容、报价
- 个人判断和备注
- 下次跟进计划

**共享层（所有购买者可见）**：
- 跟进状态（初步接触/意向明确/谈判中/已成交/无效）
- 匿名进度摘要（用户填写或选择模板）
- 最近跟进时间

共享流程：
- 用户填写私有跟进记录后，弹窗提示"您的跟进经验可以帮助其他用户判断跟单价值，系统将隐去您的个人信息，仅共享进度状态。共享后每获得 1 个'有用'标记，奖励 X 积分。[立即共享] [暂不共享]"
- 用户选择共享后，填写一句话公开摘要或选择模板
- 提交后进入待审核队列
- 后台运营审核通过后展示在跟单市场情报区
- 高等级会员（金牌及以上）共享摘要免审直接展示

共享摘要模板选项：
- 已初步接触，对方态度积极
- 正在谈判阶段，价格有商量空间
- 对方暂无合作意向
- 联系方式有效，已约定下次沟通
- 此跟单信息基本属实
- 自定义文字

市场情报聚合（跟单详情页）：

```
市场情报（基于12位购买者跟进）
─────────────────────────
跟进状态分布：
  初步接触  ████░░  40%
  意向明确  ███░░░  30%
  谈判中    ██░░░░  20%
  无效反馈  █░░░░░  10%

最新动态（匿名）：
  · 3天前：有用户标记"对方已有合作意向"
  · 7天前：有用户标记"价格谈判阶段"
  · 12天前：有用户标记"初步接触顺利"
─────────────────────────
跟单热度评分：★★★★☆（基于跟进活跃度）
```

### 5.9 邀请机制规则

- 每个用户有唯一邀请码
- 新用户注册时可填写邀请码
- 新用户注册成功后，邀请人和被邀请人均获得积分奖励（注册即发）
- 奖励金额后台可配
- 邀请记录可查询

### 5.10 分佣结算规则

分佣触发：
- 用户购买跟单时实时结算
- 平台抽取配置比例积分
- 剩余积分分佣给投稿人
- 投稿人会员等级加成计入分佣比例

分佣计算公式：
```
用户支付积分 = 跟单定价 × 会员折扣
平台抽成积分 = 用户支付积分 × 平台抽成比例
投稿人分佣积分 = (用户支付积分 - 平台抽成积分) × (1 + 投稿人等级加成)
```

结算记录：
- 每笔分佣必须记录到积分流水
- 同一笔订单只结算一次
- 跟单被判无效退款时，已发放的分佣从投稿人账户扣回

## 6. 功能模块

### 6.1 H5 用户端

#### 6.1.1 登录与用户中心
- 手机号+密码注册登录、微信授权登录（预留，mock 可切换）
- 首次登录勾选协议与隐私政策、填写邀请码（可选）
- 查看/编辑个人信息
- 查看会员等级、信用分、积分余额
- 查看我的 CRM 跟单数量、投稿跟单统计
- 页面：登录页、我的页、个人资料页、会员等级说明页、信用分说明页、用户协议页、隐私政策页

#### 6.1.2 跟单中心
- 跟单列表（分页）、分类筛选、标签筛选、搜索、排序（最新/最热/价格）
- 发现机制：猜你喜欢、热门跟单、最新上架、机会跟单
- 跟单详情摘要展示、购买解锁完整详情
- 市场情报查看（公开摘要对所有人可见，详细摘要购买后可见）
- 页面：首页/跟单列表页、跟单详情页、分类筛选页、搜索结果页

#### 6.1.3 购买与支付
- 购买确认（显示原价、折扣、实付积分）
- 超过 1 年跟单购买提示
- 积分余额不足提示充值
- 积分充值（多档位，后台可配，mock 模式模拟成功）
- 充值成功反馈、购买记录查询
- 页面：购买确认弹窗、积分充值页、购买记录页

#### 6.1.4 个人 CRM
- 我的跟单库列表、跟进状态筛选（未跟进/跟进中/已成交/已放弃）
- 下次跟进时间排序、搜索
- 跟单详情（CRM 视角）、私有跟进记录（时间线展示）
- 新增跟进记录、设置下次跟进提醒
- 共享进度入口（独立按钮，明确隔离）
- 手动录入平台外跟单、从 CRM 一键投稿
- 提醒中心（今日待跟进、逾期未跟进）
- 页面：我的跟单库页、CRM 跟单详情页、新增跟进页、手动录入跟单页、提醒中心页

#### 6.1.5 跟单投稿
- 跟单表单（标题、分类、标签、描述、联系方式、附件、预计有效期、定价）
- 图片/附件上传、相似度检测提示、提交即上架
- 我的投稿列表、被购买统计、分佣收益查看
- 页面：投稿跟单页、我的投稿列表页、投稿跟单详情页

#### 6.1.6 积分与会员
- 积分余额与流水、积分充值
- 积分收支明细（充值/消费/分佣/奖励/过期分类）
- 会员等级展示、权益说明、等级进度条
- 信用分展示与变动记录
- 页面：积分中心页、积分流水页、会员等级页、信用分页

#### 6.1.7 邀请与排行榜
- 我的邀请码、邀请海报生成、邀请记录
- 跟单达人榜（投稿被购买总量，周榜+总榜）

## 9. API 规范

### 9.1 基础规范

- 接口统一前缀：/api/v1
- RESTful 风格，返回格式统一：`{ code, message, data }`
- 错误码：0 成功 / 400 参数错误 / 401 未登录 / 403 无权限 / 404 资源不存在 / 500 服务器错误

### 9.2 鉴权规范

- H5 端：JWT（手机号登录或微信授权登录）
- 管理后台：JWT + RBAC
- Token 过期时间 7 天，含 Refresh Token 机制

### 9.3 核心接口

用户端：
- POST /auth/login（手机号/微信）
- GET /opportunities、GET /opportunities/:id、POST /opportunities
- POST /orders（购买跟单）
- POST /opportunities/:id/invalid-mark（标记无效）
- GET/POST /crm/opportunities（个人 CRM）
- POST /follow-ups（新增跟进）
- POST /follow-up-shares（共享摘要）
- POST /follow-up-shares/:id/helpful（标记有用）
- POST /points/recharge、GET /points/logs
- GET /users/me、GET /rankings、POST /invitations

管理后台：
- POST /admin/auth/login
- GET/PUT /admin/opportunities
- GET /admin/follow-up-shares/pending、PUT /admin/follow-up-shares/:id/audit
- GET /admin/users、PUT /admin/users/:id/points、PUT /admin/users/:id/credits
- GET /admin/orders、GET /admin/stats/overview、GET /admin/stats/health、PUT /admin/configs

## 13. 与现有系统的差异说明

现有《酒店供应链在线跟单系统》已实现：H5 端注册登录、跟单发布/认领/报告/确认、积分奖励、个人中心、商城兑换。

综合后的主要变化：
1. **商业模式升级**：由"免费认领+互助奖励"升级为"积分购买+分佣结算"，投稿人获得分佣收益
2. **字段分层**：新增公开/解锁字段隔离，联系方式等敏感信息付费可见
3. **新增机制**：会员等级（4 维度）、信用分、无效判定退款、相似度检测、跟进共享摘要、市场情报聚合、邀请、排行榜、通知中心
4. **新增 Web 管理后台**：完整 RBAC、跟单/审核/订单/财务/统计管理
5. **积分商城**：取消实物兑换，积分仅用于购买跟单；后台保留"积分商城"开关，未来可开启兑换功能
