# 跟单互助 · 酒店供应链在线跟单系统

面向酒店从筹建到开业全链路供应链的**供应商互助平台**（H5 端）。覆盖装修总包、弱电总包、软装总包、酒店家具、酒店运营物资等所有物资与总包服务，通过"上传跟进信息 → 互助跟进 → 成功获积分"的闭环，实现**我为人人，人人为我**。

## 核心功能

| 模块 | 说明 |
|------|------|
| 互助大厅 | 浏览 / 分类筛选 / 关键词搜索全部跟单 |
| 发布跟单 | 供应商发布自己的跟进信息，设定积分奖励 |
| 互助认领 | 其他供应商认领跟进，提交跟进报告 |
| 确认结算 | 发布者确认互助成功，互助人获得积分 |
| 积分体系 | 发布 +5、认领 +2、互助成功得奖励积分 |
| 积分商城 | 用积分兑换礼品卡、红包等实物 |
| 个人中心 | 我的发布 / 我的互助 / 积分明细 / 兑换记录 / 资料编辑 |

## 技术栈

- **前端**：React 18 + Vite + React Vant 3（H5 移动端组件库）+ React Router
- **后端**：Node.js + Express（JSON 文件存储，无外部数据库依赖）
- **通信**：前端 `/api` 反向代理至后端 3001 端口

## 快速启动

```bash
# 安装全部依赖
npm run install:all

# 同时启动前后端（前端 5173，后端 3001）
npm run dev
```

访问 `http://localhost:5173`。

也可以分别启动：

```bash
npm run dev --prefix server   # 后端 API
npm run dev --prefix client   # 前端 H5
```

## 积分规则

| 行为 | 积分 |
|------|------|
| 发布跟单 | +5 |
| 认领互助 | +2 |
| 互助成功（发布者确认） | +跟单设定的奖励（默认 20） |
| 商城兑换 | 消耗对应积分 |

等级体系：新手互助人(0) → 青铜(50) → 白银(200) → 黄金(500) → 铂金(1000)。

## 跟单状态流转

```
待认领(open) --认领--> 互助中(helping) --确认--> 已完成(done)
      \                     |
       \--关闭--> 已关闭(closed)   \--拒绝--> 回到待认领
```

## 数据存储

数据以 JSON 文件保存在 `server/data/`，已通过 `.gitignore` 排除。重启服务自动重建商城种子商品。如需重置数据，删除 `server/data/*.json` 后重启后端即可。
